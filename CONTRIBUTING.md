# Contributing

Eidos Clips is free and open source under the [MIT License](LICENSE).

```sh
swift test
bash scripts/build-app.sh
```

Next product work is in [docs/WANT.md](docs/WANT.md). Do not mark physical capture or M5 passed without evidence. Do not commit recordings, secrets, or signing credentials.

Maintain [docs/FEATURE-MAP.md](docs/FEATURE-MAP.md) and the matching `docs/features/` page whenever a feature changes. Record user entry points, observable outcomes, source/build evidence, and remaining failures; keep implementation separate from physical verification. New ideas stay labeled Proposed until selected.

Open a pull request against `main`. CI must stay green.
